# Bainbridge Law email signature

`bainbridge-signature.html` is a text-only HTML signature set in Georgia, using the site's colors: the navy "Bainbridge" and gold italic "Law" wordmark, the 40px gold rule from the footer, and the site's text grays. No images, so nothing attaches to emails and nothing breaks if a client blocks remote content.

Georgia is installed on every Mac, Windows, iOS and Android device, so the signature looks the same in every inbox. The site's EB Garamond can't be relied on in email.

## Install

Every client works the same way: open `bainbridge-signature.html` in a browser, select all (`⌘A`), copy (`⌘C`), then paste into the signature editor.

- **Gmail:** Settings → See all settings → General → Signature → Create new → paste. Set it for new emails and replies.
- **Apple Mail:** Mail → Settings → Signatures → + → paste. Uncheck "Always match my default message font" or Mail will override Georgia.
- **Outlook (Mac and new Windows):** Settings → Signatures → + → paste.
- **Outlook (classic Windows):** save the file as `Bainbridge.htm` in `%APPDATA%\Microsoft\Signatures\` and restart Outlook.
